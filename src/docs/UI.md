# UI / UX — PMB Online

## Tujuan
Desain antarmuka yang modern, bersih, responsif, dan mobile-first untuk pengalaman peserta dan operator.

## Prinsip Desain
- Mobile-first dan responsive
- Fokus pada kejelasan alur pendaftaran
- Konsistensi komponen dan warna identitas kampus
- Aksesibilitas dasar (kontras, label form)

## Komponen Utama
- Hero + CTA untuk pendaftaran
- Formulir multi-step dengan progress bar
- Halaman upload dokumen dengan pratinjau dan validasi ukuran/tipe
- Dashboard peserta: status pendaftaran, notifikasi, progress
- Dashboard admin: filter, tabel peserta, detail verifikasi
- Kartu peserta dengan QR Code dan opsi cetak/download

## Formulir
- Bagi menjadi sekumpulan step: Biodata, Pendidikan, Orang Tua, Pilihan Prodi, Dokumen
- Validasi sisi-klien sebelum submit
- Auto-save draft tiap step

## Warna & Tipografi
- Dominan: putih + warna utama kampus sebagai aksen
- Gunakan skala tipografi yang jelas untuk hierarki

## Aset Media
- Optimalkan gambar (WebP jika memungkinkan)
- Batasi ukuran upload; sediakan cropper untuk foto formal

## Responsiveness
- Grid adaptif untuk daftar dan tabel
- Tombol besar untuk aksi utama pada perangkat sentuh

## UX Flows Singkat
- Pendaftaran cepat: Landing → Registrasi → Form → Upload → Pembayaran → Verifikasi
- Admin: Login → Dashboard statistik → Verifikasi dokumen/pembayaran → Publish pengumuman
