# SMART_FILL.md

## Tujuan
Mempercepat input tanpa mengubah hasil pemeriksaan.

## Prinsip
- Membantu operator.
- Bukan diagnosis.
- Hasil bersifat indikasi.

## Fitur
- Auto hitung usia dari tanggal lahir.
- Auto kategori umur.
- Auto BMI.
- Auto klasifikasi tekanan darah.
- Auto flag faktor risiko.

## Larangan
- Tidak membuat diagnosis.
- Tidak mengubah jawaban operator.
- Tidak mengisi data yang tidak tersedia.

## Audit
Semua hasil smart fill harus dapat ditelusuri.
