# TV DISPLAY PUBLIC UI/UX

## TUJUAN
TV display harus terlihat profesional di ruang pelayanan dan aman untuk privasi.

## DATA YANG BOLEH TAMPIL
- nomor antrean
- inisial/nama depan jika perlu
- pos tujuan
- status panggilan
- informasi edukasi umum

## DATA YANG DILARANG
- NIK
- alamat
- hasil pemeriksaan
- diagnosis
- nomor HP
- data medis sensitif

## LAYOUT

```txt
[Logo + Nama Layanan + Tanggal]
[Nomor Antrean Dipanggil Besar]
[Daftar Antrean Berikutnya]
[Status Pos]
[Running Text Edukasi]
```

## VISUAL
- font sangat besar
- kontras tinggi
- animasi halus
- tidak banyak warna
- jarak lega

## AUDIO PANGGILAN
Format:
"Nomor antrean A-015, silakan menuju Pos 2."

## ACCEPTANCE
- terbaca dari jarak 5-10 meter
- tidak ada data sensitif
- tidak blank saat koneksi putus
