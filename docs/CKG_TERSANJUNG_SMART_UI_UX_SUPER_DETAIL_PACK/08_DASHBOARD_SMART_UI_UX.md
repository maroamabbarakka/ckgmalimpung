# DASHBOARD SMART UI/UX

## TUJUAN
Dashboard harus membantu keputusan, bukan hanya menampilkan angka.

## JENIS DASHBOARD

### Dashboard Operator
Fokus:
- antrean hari ini
- pasien sedang berjalan
- pos yang penuh
- tugas berikutnya

### Dashboard Admin
Fokus:
- jumlah layanan
- status finalisasi
- data bermasalah
- performa operator
- error sistem

### Dashboard Eksekutif
Fokus:
- cakupan wilayah
- tren risiko kesehatan
- kelompok usia
- wilayah prioritas

## SMART INSIGHT
Tambahkan panel:
"Yang perlu diperhatikan hari ini"

Contoh:
- 12 pasien belum final.
- Pos 3 paling lambat hari ini.
- 5 data NIK tidak valid.
- 3 export gagal.

## MOBILE DASHBOARD
Jangan tampilkan chart besar semua.
Gunakan:
- ringkasan card
- list prioritas
- chart collapsible

## ACCEPTANCE
- Dashboard operator bisa dipahami < 10 detik.
- Admin tahu masalah data tanpa mencari manual.
- Mobile tidak penuh chart berat.
