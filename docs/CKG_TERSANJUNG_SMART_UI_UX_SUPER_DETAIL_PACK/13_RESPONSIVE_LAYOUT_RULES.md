# RESPONSIVE LAYOUT RULES

## BREAKPOINT
- mobile: < 640px
- tablet: 640–1024px
- desktop: > 1024px

## MOBILE
Aturan:
- 1 kolom
- bottom action bar
- card list, bukan tabel lebar
- filter collapsible
- chart collapsible

## TABLET
Aturan:
- 2 kolom jika cukup
- patient summary sticky
- navigation compact

## DESKTOP
Aturan:
- 2-3 kolom boleh
- sidebar tetap
- tabel penuh
- dashboard grid

## FORM
Mobile:
- label di atas
- input full width

Desktop:
- boleh 2 kolom
- field penting tetap mudah terlihat

## MODAL
Mobile:
- full width
- max-height 90vh
- scroll internal

Desktop:
- max-width sesuai konten

## ACCEPTANCE
- tidak ada horizontal scroll kecuali tabel khusus.
- keyboard HP tidak menutup field aktif.
- bottom action tidak menutup konten.
