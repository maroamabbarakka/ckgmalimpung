# VISUAL DIRECTION — PROFESSIONAL HEALTH APP

## TUJUAN
Tampilan aplikasi harus terasa seperti sistem kesehatan profesional, bukan dashboard umum.

## ARAH VISUAL
- bersih
- tenang
- jelas
- tidak ramai
- warna fungsional
- ruang lega
- fokus pada tindakan

## BRAND FEEL
Gunakan nuansa:
- teal/hijau kesehatan sebagai warna utama
- biru untuk informasi
- hijau untuk selesai
- amber untuk proses/peringatan
- merah hanya untuk error/kritis

## HAL YANG DIHINDARI
- gradient berlebihan
- bayangan terlalu berat
- terlalu banyak icon warna-warni
- chart memenuhi layar
- kartu statistik terlalu ramai
- font terlalu besar di mobile
- font terlalu kecil di tabel

## CARD STYLE
Setiap card:
- background putih
- border tipis
- radius 16px
- shadow ringan
- title jelas
- isi tidak terlalu padat

## ICON STYLE
Gunakan icon:
- outline
- ukuran konsisten 18-22px
- tidak terlalu dekoratif
- selalu ada label untuk aksi penting

## ACCEPTANCE
- layar terlihat profesional saat dibuka di ruang pelayanan
- operator bisa memahami prioritas kerja tanpa diarahkan
- tampilan mobile dan desktop terasa satu keluarga
