# OPERATOR TRAINING MODULE

## TUJUAN
Membuat operator paham alur kerja tanpa bergantung pada developer.

## SESI 1 - Dasar
Materi:
- login
- logout
- role masing-masing
- cara membaca dashboard
- cara melihat antrean

## SESI 2 - Loket
Materi:
- input pasien
- validasi NIK
- pasien tanpa NIK
- koreksi data
- panggil antrean

## SESI 3 - Pos Pemeriksaan
Materi:
- membuka pasien
- mengisi form
- menyimpan draft
- melanjutkan ke pos berikutnya
- finalisasi

## SESI 4 - Admin
Materi:
- kelola staff
- export
- audit log
- monitoring error
- data cleaning

## UJI KOMPETENSI
Setiap operator harus bisa:
- login mandiri
- input 1 pasien dummy
- menyelesaikan 1 alur dummy
- logout
