# Ringkasan Prioritas Untuk Pimpinan/Owner

## Fokus Utama
Aplikasi tidak perlu langsung ditambah banyak fitur baru. Fokus terbaik adalah membuat fitur yang sudah ada menjadi aman, stabil, konsisten, dan nyaman dipakai.

## Prioritas 1
Keamanan login, role, dan data pasien.

## Prioritas 2
Alur pasien antar pos harus terkunci dan tidak bisa lompat sembarangan.

## Prioritas 3
Tampilan mobile harus dibuat nyaman untuk petugas lapangan.

## Prioritas 4
Dashboard harus membantu keputusan, bukan hanya menampilkan angka.

## Prioritas 5
Aplikasi harus tahan internet putus dan browser refresh.

## Keputusan Yang Perlu Didukung
- Beri waktu refactor, jangan hanya minta tambah fitur.
- Wajibkan testing mobile.
- Wajibkan backup sebelum update besar.
- Wajibkan dokumentasi perubahan.
- Wajibkan setiap developer memakai checklist anti-skip.
