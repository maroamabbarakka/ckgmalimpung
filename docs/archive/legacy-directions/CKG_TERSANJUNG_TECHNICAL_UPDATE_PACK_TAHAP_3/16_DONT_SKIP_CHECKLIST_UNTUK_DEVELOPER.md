# Checklist Anti-Skip Untuk Developer

Sebelum mengirim hasil update, jawab YA/TIDAK.

## Kode
- [ ] Saya sudah menjalankan build.
- [ ] Saya sudah cek console browser.
- [ ] Saya tidak menambah hardcoded role baru.
- [ ] Saya tidak menambah style UI acak.
- [ ] Saya tidak mengubah schema tanpa catatan.
- [ ] Saya tidak menghapus field lama tanpa fallback.

## UI
- [ ] Saya cek mobile 360px.
- [ ] Saya cek desktop.
- [ ] Tombol utama terlihat.
- [ ] Loading state ada.
- [ ] Empty state ada.
- [ ] Error state ada.

## Data
- [ ] Save berhasil.
- [ ] Edit berhasil.
- [ ] Data lama tetap terbaca.
- [ ] Tidak ada overwrite diam-diam.
- [ ] Audit log dibuat jika mengubah data penting.

## Dokumentasi
- [ ] Issue/PR dijelaskan.
- [ ] Changelog internal diisi.
- [ ] Screenshot before/after disediakan untuk UI.
