# PRIVACY BY DESIGN UI

## TUJUAN
Tampilan harus melindungi data pasien sejak desain, bukan hanya dari rules.

## ATURAN TAMPILAN

### Daftar Pasien
Tampilkan:
- nama
- usia
- nomor antrean
- status pos

Samarkan:
- NIK: 7309********1234
- nomor HP: 08******1234

### Detail Pasien
Data lengkap hanya untuk role yang berwenang.

### TV Display
Tidak boleh tampil:
- NIK
- alamat
- hasil medis
- diagnosis
- nomor HP

### Export
Sebelum export:
- tampilkan modal konfirmasi
- jelaskan data apa yang diexport
- log aktivitas export

## SCREEN PRIVACY
Untuk data sensitif:
- gunakan label jelas
- hindari tampilkan semua di dashboard umum
- gunakan section collapsible untuk data sensitif

## ACCEPTANCE
- layar publik tidak bocor data pribadi
- role viewer tidak melihat data rinci
- export selalu dikonfirmasi dan dilog
