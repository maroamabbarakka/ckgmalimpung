# EMPTY, LOADING, ERROR STATES

## LOADING
Gunakan skeleton sesuai konteks:
- card skeleton
- table skeleton
- form skeleton
- dashboard widget skeleton

Hindari:
- spinner fullscreen terlalu lama
- layar putih

## EMPTY STATE
Contoh:
- Belum ada pasien hari ini.
- Belum ada data antrean.
- Tidak ada hasil untuk pencarian ini.
- Belum ada laporan yang bisa diexport.

Sertakan aksi:
- Tambah Pasien
- Reset Filter
- Coba Lagi

## ERROR STATE
Error harus:
- jelas
- ramah
- memberi solusi

Contoh:
"Data gagal dimuat. Periksa koneksi internet, lalu coba lagi."

Tombol:
- Coba Lagi
- Kembali
- Laporkan Error

## OFFLINE STATE
Tampilkan banner:
"Anda sedang offline. Data baru akan disinkronkan saat koneksi kembali."

## ACCEPTANCE
- Tidak ada halaman blank.
- Semua error punya tombol aksi.
- Offline status terlihat.
