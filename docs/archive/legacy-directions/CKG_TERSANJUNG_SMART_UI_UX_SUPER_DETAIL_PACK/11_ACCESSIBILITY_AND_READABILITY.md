# ACCESSIBILITY & READABILITY

## FONT
Minimal:
- body 14px desktop
- body 16px mobile untuk form
- caption minimal 12px

## KONTRAS
Hindari:
- teks abu terlalu muda
- tombol warna soft tanpa border
- teks kecil di background warna

## TOUCH TARGET
Semua tombol mobile:
- minimal 44x44px

## FOCUS STATE
Input aktif harus terlihat jelas:
- border primary
- ring soft
- label jelas

## KEYBOARD
Pastikan:
- tab order logis
- modal trap focus
- ESC menutup modal

## SCREEN READER BASIC
Tambahkan:
- aria-label untuk icon button
- label untuk input
- role alert untuk error penting

## ACCEPTANCE
- Form bisa dipakai tanpa mouse di desktop.
- Tombol nyaman disentuh di mobile.
- Error terbaca jelas.
