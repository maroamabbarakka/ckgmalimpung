# FINAL DONE DEFINITION

Developer tidak boleh menandai pekerjaan selesai sebelum ini terpenuhi.

## DONE BERARTI

- fitur berjalan
- fitur lama tidak rusak
- mobile aman
- desktop aman
- error tertangani
- loading state ada
- rules tidak dilonggarkan
- audit log aktif untuk aksi penting
- ada catatan testing

## BUKAN DONE

- hanya berhasil build
- hanya berhasil di laptop developer
- hanya UI terlihat berubah
- belum dites offline
- belum dites role lain
