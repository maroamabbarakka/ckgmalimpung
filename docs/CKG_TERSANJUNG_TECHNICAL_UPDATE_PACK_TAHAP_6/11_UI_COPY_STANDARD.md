# UI COPY STANDARD

## GAYA BAHASA

Gunakan bahasa jelas, pendek, dan membantu.

## CONTOH ERROR

Jangan:
- Error Firebase permission-denied

Gunakan:
- Anda tidak memiliki akses untuk membuka data ini.

Jangan:
- Failed to fetch

Gunakan:
- Koneksi bermasalah. Periksa internet lalu coba lagi.
